# 📊 Vrinda Store Data Analysis Dashboard

## 🔍 Project Overview
This project presents a comprehensive sales analysis of Vrinda Store using Google Sheets. The goal is to derive meaningful business insights through data visualization and interactive dashboards.

---

## 🎯 Objectives
- Analyze monthly sales trends
- Compare sales between men and women
- Identify top-performing states
- Understand order status distribution
- Analyze sales channels performance

---

## 📊 Dashboard Features
- 📅 **Monthly Sales Analysis** – Track revenue trends across months  
- 👨‍👩‍👧 **Gender-based Sales** – Compare men vs women contribution  
- 📦 **Order Status Breakdown** – Delivered, Cancelled, Returned insights  
- 🌍 **Top 5 States** – Highest sales generating regions  
- 🎯 **Age vs Gender Analysis** – Customer segmentation  
- 🛒 **Sales Channels** – Amazon, Flipkart, Myntra, Ajio, etc.

---

## 🛠 Tools & Technologies Used
- Google Sheets
- Pivot Tables
- Data Cleaning
- Charts & Graphs
- Dashboard Design

## 📈 Key Insights
- Women contribute approximately **64%** of total sales  
- **Amazon** is the leading sales channel  
- Majority of orders are successfully **delivered**  
- A few states dominate overall sales performance  
- Adult age group contributes the most to sales
